# Security policy

## Reporting a vulnerability

Please report a suspected vulnerability privately, through GitHub: open the [Security tab](https://github.com/mixOmics-org/mixOmics/security) of this repository and choose "Report a vulnerability". GitHub describes the steps in [Privately reporting a security vulnerability](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).

If you cannot use GitHub for this, email <security@mixomics.org> instead.

Please do not open a public issue or post on the forum about it.

It helps if the report says:

- which version of mixOmics and of R you used;
- what the problem is and how to reproduce it;
- what you think its effect is.

A maintainer will reply through the same private report, or by email if you wrote by email.

## Supported versions

Fixes are made in the development version and, where needed, in the current Bioconductor release. Earlier releases are not updated.
